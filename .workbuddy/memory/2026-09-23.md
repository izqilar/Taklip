## 10:58 运营端视角间检索框串号缺陷修复（视角隔离）
- 根因：layerContext.objectScope 是单一全局 state；LayerHeader.onViewChange 切视角时调 setObjectScope(null) 清全局槽位。故 agent 视角选中账号后切到 provider，provider 检索框仍显示 agent 的账号（串号）。
- 修复（按视角隔离）：
  1. layerContext.tsx：objectScope 改为 Record<LayerKey,...> 的 scopesByView，取数派生 scopesByView[view]；setObjectScope 只写当前视角槽位；setView(v) 同步把 scopeStore._subject 切到目标视角自身槽位（同步执行，避免新视角请求带旧 subject）；角色更换时 setSubject(null) 清残留。
  2. LayerHeader.tsx：删除切视角时的 setObjectScope(null)（会抹掉源视角保留对象），改为只 setView+navigate。
  3. ObjectScopeBar.tsx：加 [view] 副作用，切视角时输入框回落到当前视角自己槽位的对象（或空），清下拉/展开。
  4. App.tsx 的 ObjectScopeInvalidationBridge：加 view 感知——仅同视角内 subject 变化才 invalidate 全量；切视角不失效（路由 remount + setView 已同步 subject），避免用旧 subject 跑错请求。新增 import type { LayerKey }。
- 行为：各视角独立记忆自己选中账号；切视角不串号；未选对象的视角检索框为空；后端未改，无需重建。admin tsc --noEmit 通过；:5174 / :3000 存活。未 commit。
