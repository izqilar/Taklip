## 编辑器「组件」菜单 24 个 widget 组件落地（#263 + #265）

### 架构决策（CORE）
- 不新增 24 个 ElementType，而是引入单一 `ElementType='widget'` + 判别字段 `widget: WidgetKind` + 通用配置袋 `data: Record<string,any>`
- 三层分发（EditorCanvas / DOMRenderer / ComponentSettingsPanel）各加 `case 'widget'`，内部按 `WIDGET_REGISTRY[el.widget]` 数据驱动渲染
- `WIDGET_REGISTRY: Record<WidgetKind, WidgetDef>`：每个 WidgetDef 声明 `kind/labelKey/icon/category/defaultSize/createDefault/commonFields/fields/DOM`
  - `commonFields`：顶层 WidgetElement 属性（title/text/themeColor/textColor/bgColor）
  - `fields`：`data` 袋中键，类型 text/textarea/number/color/switch/image/select/options
- `WIDGET_REGISTRY` 由 `apps/web/src/elements/widget/widgetModules.tsx` 定义（24 个 DOM 渲染函数 + 注册表）；`registry.tsx` 复导出 `getWidgetDefault` 供菜单调用
- 新增文件：`packages/core/src/schema.ts`(+widget/WidgetKind/WidgetElement)、`constants.ts`(createElement case)、`apps/web/src/elements/widget/{types.ts,widgetModules.tsx,CanvasWidget.tsx,DOMWidget.tsx,PropertyWidget.tsx,registry.tsx}`、`ComponentLibraryMenu.tsx`(24 个 widgetItem 占位替换)、editor.json(zh-CN/en) 的 `element.widget` + `widget.fields.*`
- 24 个 WidgetKind：viewCount/dynamicNumber/screenshot/table/vote/relay/dataChart/quiz/lottery/quickForm/inputBox/idCard/dropdown/multiSelect/singleSelect/rating/uploadImage/formCount/region/wechatNickname/wechatAvatar/wechatAvatarWall/workCover/workTitle
- 交互状态持久化：vote/relay/quiz/rating/viewCount/uploadImage/formCount 用 per-element-id localStorage；quickForm/inputBox 用全局 `h5design_formcount` 自增；计数仅在 `window.location.pathname.startsWith('/p/')`（发布页）触发，避免编辑器重复计数
