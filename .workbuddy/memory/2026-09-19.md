## 统一登录入口：A（反向桥接）+ B（服务端 ROLE_HOME 单一真值）

### B. 服务端：角色 → 落点，单一真值
`apps/server/src/auth/auth.service.ts`：新增模块级 `ROLE_HOME`
（USER→{web,/user/works}、SERVICE_PROVIDER→{admin,/sp/studio}、AGENT→{admin,/agent/dashboard}、
ADMIN→{admin,/admin/dashboard}）；`generateTokens()` 在返回体里**与 user 平级**下发 `home`
（login/register/refresh 三处同时生效）。origin 是逻辑端标识（web/admin），由前端映射为基址，服务端不硬编码域名。

### A. 运营端：终端用户「走错门」→ 自动桥接回 web 端
`authProvider.login`：
- 非准入角色时**不写运营端任何会话**（`setSession` 不调用），改为把 JWT+user 以
  `?token=&user=` 拼成 `bridge` 地址（复用 AccountPill「返回 Web 端」同一套参数协议，web `bootstrap.ts` 消费）。
- 准入角色：`setSession(token, {...user, home})` 落盘；`return { success:true, ...(home?.origin==='admin'?{redirectTo:home.path}:{}) }`。
- `Login.tsx`：`LoginErr` 加 `bridge?`；命中后 `setTimeout 1500ms` 自动跳转（`useEffect` 清理定时器），
  Alert 同时给链接（点击立即走）+ `description`「正在跳转到用户端工作台，请稍候…」。
- ⚠️ Refine `HttpError` 精确类型：额外字段一律用**对象展开**写入（`...(cond?{name,bridge}:{})`），不要直接写字面量属性。

### web 端：改为按 home 分流（修掉一个老 bug）
`Login.tsx` 原判定 `role === 'SERVICE_PROVIDER' || role === 'AGENT' || 'ADMIN'` —— **最后一项 `'ADMIN'` 是常量字符串恒真**，
等于所有角色（含 USER）登录 web 端都被踢到 :5174，USER 再被 403 拦下。现改为 `home?.origin === 'admin'` → `buildAdminUrl(home.path)`；
否则 `navigate(from ?? home?.path ?? '/user/works')`（来源页优先）。
`authStore.login/register`：服务端 `home` 与 user 平级下发 → **必须并入 user 再落盘**（`{...res.user, home}`），
否则 `user.home` 恒 undefined；`refreshAccessToken` 里也要保 home 不被抹掉（新响应无 home 时与旧值 merge）。
`UserInfo.home?`、`AuthResponse.home?` 类型已补。
