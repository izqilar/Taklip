### 22:x 修复视频导出「仅第一页完整、第二页起对象丢失/动画截断」

1. **全程单一 React root + 单一 Konva.Stage**；切页只让 `<Layer key={'layer-'+pageIndex}>` 按 key 重挂载（同 Stage 换 Layer），彻底规避多 Root 生命周期问题。
