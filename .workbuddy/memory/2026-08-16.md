## 「我的作品」缩略图加载缓慢 — 懒渲染优化（仅做方案 1）

- **做法**：`apps/web/src/components/SchemaThumbnail.tsx` 增加 `IntersectionObserver` 懒渲染 + 骨架占位：

  - 老浏览器不支持 `IntersectionObserver` 时降级为直接渲染（`setInView(true)`）。
  - 等比缩放逻辑（`ResizeObserver`）保持不变，缩略图对外契约不变（仍 `absolute inset-0` 填充父 `relative` 容器），对模板墙/首页复用方均安全。

## 修复动画预览清理可能触发的右侧面板崩溃
- **问题**：给对象附加动画后点击画布空白，右侧属性面板报错。
- **根因分析**：`apps/web/src/animations/konvaPlayer.ts` 把注册表中的 `scale` 直接当作 Konva Node 的数值型 setter 使用，但 Konva 的 `node.scale()` 实际接收 `{x, y}` 对象；播放含缩放的入场动画（如 bounceIn、zoomIn）时会异常。若此时点击画布空白导致组件卸载、触发清理函数继续访问异常/已销毁节点，崩溃会扩散到右侧面板。
- **改动文件**：`apps/web/src/animations/konvaPlayer.ts`
  - 新增 `snapshotNode` / `applyState` 辅助函数，操作前检查 `node.isDestroyed()`。
  - 从 `ANIMATABLE_PROPS` 移除 `scale`，在 `computeStates` 里把 `scale` 映射为 `scaleX` + `scaleY`，避免错误调用 `node.scale(number)`。
  - 统一用 `applyState` 替换所有内联属性设置/恢复循环，代码更简洁且带销毁检查。
- **验证**：`apps/web` typecheck **EXIT 0** ✅；dev server `http://localhost:5173/editor/test` 返回 200。


## 修复预览动画第二次点击无效与取消选择后面板崩溃
- **问题**：
  1. 给对象设置动画后点击「预览动画」按钮，第一次能播放，第二次点击无响应。
  2. 点击画布空白取消选择后，右侧属性面板报错：`Cannot read properties of undefined (reading 'destroy')`。
- **根因分析**：Konva 的 `Node.prototype.to(config)` 内部会自己创建 `Konva.Tween`、自动调用 `.play()`，并在 onFinish 中自动 `this.destroy()`，但**不返回任何实例**。代码中把 `node.to(tweenConfig)` 的返回值当成 `Konva.Tween` 实例保存，实际是 `undefined`。第一次播放还能工作是因为 `node.to()` 内部已启动动画；但保存的 `tween` 是 `undefined`，第二次点击/组件卸载时调用 `tween.destroy()` 就会触发 `undefined.destroy()` 的崩溃。
- **改动文件**：
  - `apps/web/src/animations/konvaPlayer.ts`
    - 改用 `new Konva.Tween(tweenConfig)` 显式创建 tween 实例并持有引用，确保 `tween.destroy()` 安全。
    - 新增 `safeDestroyTween` 辅助函数，对已经销毁或异常的 tween 做防御式清理。
    - 重构 `playAnimationOnNode`：统一状态快照/恢复逻辑，增加可选 `onComplete` 回调。
    - 重构 `playAnimationsOnNode`：基于 `playAnimationOnNode` 串行播放，单个动画完成后自动播放下一个；返回的 cleanup 可安全中断并恢复设计态。
  - `apps/web/src/components/Panel/ComponentSettingsPanel.tsx`
    - `playPreview` 和组件卸载 cleanup 用 `try/catch` 包裹，即使旧 cleanup 抛错也不会阻塞流程/导致面板崩溃。
- **验证**：`apps/web` typecheck **EXIT 0** ✅；dev server `http://localhost:5173/editor/test` 返回 200。
