### 关键设计决策：两张派发表
原型是静态 demo，**切视角即换人**；本 app 胶囊是**操作员锚点**（人不变、视角变）。因此拆分：
- **todos 按 operator 角色派发**（ADMIN 待审入驻/模板/提现/公告；AGENT 待审服务商/待打款/未关工单/待审公告；SP 待接单/待审模板/待打款/未关工单；USER 为 `[]`——运营端本就拦 USER 登录，不伪造数字）
- **links / tools 按当前 VIEW 层派发**（console/agent/provider/user 四套，tools 都含「账户详情」→ `/account/profile`）

### 修复的真实缺陷
- **`LayerProvider` 挂在 `<Refine>` 之外**（`App.tsx`）→ `initialView()` 在登录页就跑完（role undefined → 落 `console`），登录后**永不重跑**。AGENT/SP 一直卡在总台层：侧栏、面包屑全错，账号面板也跟着错。修法：`LayerProvider` 移入 `<Refine>`，并在 `layerContext.tsx` 用 `useGetIdentity` 监听 role 变化重新定层（`initialView()` 改名 `viewOfRole(role?)`）。验证后面包屑正确显示「代理商中心/辖区概览」「服务商中心/我的工作台」。

### 踩坑
1. **菜单名与角标不要内联拼接**：之前误把 `.lbl` 里的文本写成「服务商管理+3」。正确做法是文本保持纯净，角标作为兄弟元素右对齐。

5. **Playwright config 路径问题**：`--config e2e/playwright.config.ts` 会导致 `testDir: './e2e'` 被解析为 `e2e/e2e`，从而 No tests found。本次用独立 `.cjs` 冒烟脚本验证，不依赖该配置。
