## P0 阶段开发 — 画布编辑器引擎深化

### 完成内容
1. **增强 Store**（`store/editorStore.ts`）：
   - Undo/Redo 历史栈（past/future 快照，MAX_HISTORY=50，pushHistory + undo + redo）
   - 复制/粘贴（clipboard + copyElement + pasteElement）
   - 复制副本（duplicateElement）
   - 多页面管理（addPage/deletePage/switchPage/renamePage/reorderPages/setPageBackground）
   - API 集成状态（projectId/isSaving/isDirty/isLoading + loadProject/newProject）
   - Selector hooks（useSelectedElement/useCanUndo/useCanRedo）

2. **元素注册表**（`elements/registry.ts`）：
   - registerElement 注册系统：每种元素注册 { type, label, icon, baseFields, typeFields }
   - 5 种内置元素全部注册：text/rect/circle/line/image
   - PropertyField 类型系统：number/text/color/select/slider/textarea
   - getPropertyFields(el) 返回该元素的所有可编辑属性
   - getAllRegisteredElements() 供素材面板动态渲染

3. **全属性面板**（`components/Panel/PropertyPanel.tsx`）：
   - 从注册表动态渲染属性编辑器
   - 支持所有字段类型：数字/文本/颜色/选择/滑块/文本域
   - 通用属性（X/Y/宽/高/旋转/透明度）+ 类型专属属性（字号/填充/圆角等）
   - 未选中元素时显示页面背景色编辑
   - 操作按钮：置顶/置底/复制/删除

4. **键盘快捷键**（`hooks/useKeyboard.ts`）：
   - Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做
   - Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+D 复制副本
   - Delete/Backspace 删除
   - 方向键微调 1px、Shift+方向键 10px
   - Ctrl+] 置顶、Ctrl+[ 置底
   - 输入框内不拦截

5. **多页面管理**（`components/Panel/PageBar.tsx`）：
   - 底部页面栏：添加/删除/切换/重命名
   - 当前页面高亮，hover 显示操作按钮
   - 至少保留 1 页（禁止删除最后一页）

6. **前后端联调**：
   - `api/client.ts`：封装 listProjects/getProject/createProject/updateProject/deleteProject
   - `pages/ProjectList.tsx`：作品列表页，展示所有作品卡片，支持创建/打开/删除
   - `pages/Editor.tsx`：编辑器路由页，从 API 加载作品 schema
   - `components/Editor/EditorApp.tsx`：编辑器主组件，含保存（手动+自动30s/失焦）、返回列表
   - `App.tsx`：react-router-dom 路由配置（/ 列表页、/editor/:projectId 编辑器页）
   - API 代理：vite.config.ts 中 /api 代理到 localhost:3000，API client 用相对 URL

7. **吸附对齐辅助线**（`components/Canvas/EditorCanvas.tsx`）：
   - 拖动时检测与其他元素/画布边缘的对齐（左/中/右、上/中/下）
   - SNAP_THRESHOLD=6px，吸附时显示蓝色虚线辅助线
   - dragStart 时 pushHistory，dragEnd 时清除辅助线
   - 图片元素支持 HTMLImageElement 加载

8. **素材面板更新**（`components/Panel/MaterialPanel.tsx`）：
   - 从注册表动态读取元素列表
   - 快捷键提示区
