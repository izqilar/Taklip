### 坑（可复用）
- **admin dev server 仅绑 IPv6** → Playwright `BASE` 用 `http://localhost:5174`（解析到 `[::1]`），不能用 `127.0.0.1`。
- **详情按钮定位**：`span:hasText('详情')` 会命中侧栏「账户详情」菜单 → 必须限定 `tbody tr span:hasText('详情')` + `waitForFunction(()=>location.pathname.startsWith('/sp/works/'))`。
- **bash 内联 token 解析易空**：先 `RAW=$(curl login)` 再 `printf '%s' "$RAW" | node -e` 提取 `accessToken`，避免管道子 shell 取值异常。
