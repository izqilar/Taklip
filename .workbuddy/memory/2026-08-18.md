## 修复「日历组件无法移动/选中」(17:xx)
- 现象：日历能插入画布，但鼠标拖不动、也选不中。
- 根因（BUG）：`apps/web/src/elements/calendar/CanvasCalendar.tsx` 中根 Group 的**所有子节点（背景 Rect、标题、星期、日期网格、标记）都设了 `listening={false}`**。Konva 的命中检测是子节点命中区域的并集，当整棵子树都不可命中时，根 Group 没有任何可点击像素，于是 `draggable`/`onClick` 等事件无法触发 → 既不能选中也不能拖动。其它元素（如 rect）底层形状默认 `listening` 为真，充当命中目标，所以没有此问题。
- 修复：把背景 `<Rect>` 的 `listening={false}` 去掉，让它作为整块日历的命中目标（其余装饰子节点仍保持 `listening={false}` 即可），根 Group 即可正常接收 `common` 传入的 `draggable`/`onClick`/`onDragEnd`，拖拽与选中恢复。
- 同步简化：`MarkerShape` 的 `heart` case 原在 switch 分支内裸声明 `const s`，存在作用域泄漏隐患，已用 `{}` 块作用域收敛（行为不变）。
- 验证：pnpm typecheck 全绿；pnpm build 成功（先移开旧 dist 规避 safe-delete 老问题）。代码审查脚本：0 严重 / 0 一般 / 24 优化建议（多为命名风格误报，与项目 TSX 约定不冲突，未改动）。

## 修复「日历年份向右溢出组件」(19:20)
- 现象：已插入的日历组件中，右侧年份（如 2026）超出组件右边界，详见截图。
- 根因：`CanvasCalendar` 中年份 Text 设了 `x={innerW - 1}` 和 `align="right"`，但 Konva 的 `Text` 必须给定 `width` 后 `align` 才生效，否则文字仍从 `x` 向右绘制，导致溢出。`DOMCalendar` 的年份 span 用了 `right: 0` 却未设 `width`/`textAlign`，同样会溢出。
- 修复：
  - `apps/web/src/elements/calendar/CanvasCalendar.tsx`：年份改为 `x={0} width={innerW} align="right"`，让文字右边缘贴齐内边界。
  - `apps/web/src/elements/calendar/DOMCalendar.tsx`：年份 span 增加 `width: innerW` 和 `textAlign: 'right'`，与编辑态严格对齐。
- 验证：pnpm typecheck 全绿；pnpm build 成功（仅有既有 chunk 体积提示）。
