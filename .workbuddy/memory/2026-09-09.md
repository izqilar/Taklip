## 十九、M2 三次修正：admin 作品卡渲染与 web 完全一致（修复 Tailwind 在 admin 端失效）

### 问题
用户第三次反馈 5174/user/works 的"新郎风采"缩略图与 5173/dashboard 不一致：5174 顶部缺失"我要结婚了"黑胶囊，只显示中间时间轴，仿佛页面被放大且仅露出中间部分。

### 深度排查
- 确认两端返回的 schema 完全一致（同一个 Project id，pages=2，elements=3，cover=null）。
- 用 Playwright 同时 dump 两端同一卡片的 DOM 计算样式：
  - web 端 `SchemaThumbnail` 容器 `absolute inset-0` 生效，渲染器 `transform: scale(0.618667)`，页面 375×667 被等比缩放到 232×412，完整填入封面容器。
  - admin 端 `SchemaThumbnail` 容器**没有** `absolute inset-0`，尺寸变成 375×667（未缩放），页面左上角位于封面容器外部；封面容器 `overflow:hidden` 只截到页面中间区域，因此"我要结婚了"被裁掉。

### 根因
`apps/admin` **没有启用 Tailwind CSS**，而 `packages/render/src/SchemaThumbnail.tsx` 内部使用 Tailwind 类名（`absolute inset-0 h-full w-full overflow-hidden` 等）做缩略图容器样式。在 admin 端这些类名没有对应 CSS，导致：
- 容器不是 absolute 定位，无法填满封面区。
- 容器没有 `width/height: 100%` 和 `overflow: hidden`。
- `ResizeObserver` 读取的 `clientWidth` 为 0，等比缩放比例保持默认 `scale=1`，整页以原始 375×667 渲染，只被外层封面容器裁剪出中间一块。

### 修复
`packages/render/src/SchemaThumbnail.tsx` 全面去 Tailwind，改为**内联 style**：
- 主容器：`position: absolute; inset: 0; width: 100%; height: 100%; overflow: hidden`
- 错误边界占位：用 `display:flex; align-items:center; justify-content:center; backgroundColor:#f3f4f6` + 文字样式
- 骨架屏：`linear-gradient(135deg,#f3f4f6,#e5e7eb)` + `animation: pulse 2s ...`
- 注释同步说明："本组件属于共享渲染器，需在三端保持一致，因此不使用 Tailwind 类名，全部使用内联 style"

### 验证
- `pnpm -F @h5design/render -F @h5design/web -F @h5design/admin run typecheck` 全部 0 错误。
- 强制重启 web(:5173) 与 admin(:5174) vite 后，Playwright E2E 对两端"新郎风采"卡片截图对比：
  - admin 封面容器 234×416，渲染器 `scale=0.624`，容器与封面完全重合。
  - "我要结婚了"元素在页面内 `top=62.97px`，与 web 完全一致。
  - 两端截图均为完整首屏（顶部黑胶囊 + 人物照片），无裁切。
- 临时对比脚本 `apps/admin/temp/compare-rendering.cjs` 与 `compare-out/` 已清理。

### 关键结论
共享渲染器 `@h5design/render` 作为跨端包，**禁止依赖 Tailwind 类名**；必须全部使用内联 style 或标准 CSS，确保 web/admin/小程序三端样式一致。本次修复后，admin 与 web 的作品缩略图真正做到"同一 JSON、同一渲染器、同一像素效果"。
