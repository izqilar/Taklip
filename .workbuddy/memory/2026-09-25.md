## 新客户注册为代理商/服务商方案（设计稿，未实施）
产出 `docs/新客户注册为代理商或服务商方案.md`。**推荐方案：扩展现有注册流程（注册页加账户类型），

核心设计：两段式提交 —— `POST /api/auth/register` 只扩轻量可选字段（intent/realName/regionId，
**不承载证件附件、不写 role**），注册后持 token 走既有受保护接口 `/api/user/qualifications` 提交材料。

核实到的新缺口（本轮发现，方案需一并解决）：
- 总台 `POST /api/user/qualifications/:id/review`（user-console:1352，@Roles ADMIN）body 仅
  `{pass, final}`，**不接 note**，且 `QualificationApplication` 无 `reviewNote` 字段 → 驳回原因无处落库。
- 入驻管线**无任何结果通知**（JOIN 隧道有 `staff.service.notifyJoinResult` 写 Message scope=USER，
  入驻没有）；"初审通过"只是 user-console:899 的通知聚合，非审核回执。
- `DELETE /api/user/qualifications/:id`（user-console:1326）是**物理 delete**，审计留痕丢失，
  与 JOIN 隧道 `WITHDRAWN` 软删除语义不一致。
- `certNo` 无唯一约束 → 换手机号即可重复入驻（手机号唯一挡不住）。
- 入驻入口 `apps/web/src/user/Apply.tsx` 挂 `ProtectedRoute`（App.tsx:85~105）下，
  新客户必须先注册登录才能申请 —— 注册页无账户类型（Register.tsx 仅手机/密码/昵称）。
- 仓库 `apps/` 只有 admin/server/web，**无独立 APP 工程**；用户口中的"APP"= web H5。

  - ★真根因（由 Playwright 冒烟抓出）：区域三级反查 effect 在**首帧** `prefill` 仍为 null（消费 effect 的 setState 未提交）时误置 `prefillRegionDone=true` 短路，导致省/市/区**永远填不上**。修复：`if (!prefill) return;`（未就绪不标记完成），待 prefill 与区域树都到位再 `resolveRegionByPath` 反查并置位。区域树节点确实带 `regionPath`（省=11/市=11/1101/区=11/1101/110101），故只需修 effect 时序。
- **缺陷2（总台消息中心无法处理入驻终审）**：`Message` 加 `bizType/bizId`（可空）+`@@index([bizType,bizId])`；`fillQualification` 进入 FINAL_PENDING 时向总台投递 `scope=OWN,targetRole=ADMIN,bizType=QUALIFICATION,bizId=app.id` 待办消息；`inbox()` 对 ADMIN 返回全部已发布 → 该待办可见。新增 `GET /api/admin/qualifications/:id`（含 user/审核人/历史数）。前端：新建整页 `apps/admin/src/pages/qualificationDetail.tsx`（默认只读 Descriptions；`?mode=review` 或点「审核」→ 部分字段可编辑 + 修改意见，「审核通过」=final pass 可带 corrections，「驳回」须填原因）；`messages.tsx` 收件箱加「操作」列，「查看/审核」直达该整页。
- **验证**：API 层 15/15（fill→FINAL_PENDING+待办、消息中心可见、详情、review→APPROVED+corrections 合并+角色升级）；Playwright 真实浏览器 10/10（D1 提示条+说明+区域三级预填；D2 待办行→详情可编辑→审核通过→APPROVED）。测试数据（UI_/SMOKE_ 前缀）已清理，DB 残留 0。
- **环境备忘**：Playwright 需先 `playwright install chromium`；本机仅下到完整版 `chromium-1234`（无 headless-shell），须 `chromium.launch({executablePath:'~/.cache/ms-playwright/chromium-1234/chrome-win64/chrome.exe'})`。server 重启：`Start-Process node scripts/server-watchdog.js <root>`（PowerShell，勿用 Git Bash 的 `cmd /c start`，会被破坏）；`:3000 /health` 200 即就绪。
