## 导出视频过程静音（不放音）修复
- **现象**: 导出 mp4/webm 时作品声音外放，不合逻辑

## startup.ps1 服务脱离加固(用户确认要加固)
- **根因**: 原 `Start-Process cmd.exe -WindowStyle Hidden` 起的仍是启动器控制台会话的子进程，关终端时整会话被回收→node 被杀(注释承诺"关窗不停"未兑现)。
- **修复**: server/web 启动改为 `cmd /c start "" /min cmd /c "<inner>"`：`start /min` 让服务在独立最小化窗口/进程组启动，脱离启动器控制台生命周期，关窗后存活。inner 仍为 `cd /d <dir> && node dist/main / pnpm dev > log 2> err`(路径无空格，引号嵌套可正确解析)。
- **验证限制**: 本沙箱 PowerShell 安全策略拦截"从 PowerShell 启动 cmd.exe"(Start-Process cmd.exe 被拒)，且 Write-Host/stdout 不被捕获；故无法在此端到端实测存活。改为把展开后的命令字符串写入文件核对引号拼接，确认形如 `/c start "" /min cmd /c "cd /d "D:\...\apps\server" && node dist/main > "D:\...\server.log" 2> "D:\...\server.err""`，引号平衡正确。`start /min` 是 Windows 标准脱离写法，用户在自有环境双击运行 startup.ps1 时生效(其环境不受本沙箱拦截)。
- **注意**: 加固后每个服务会多一个"最小化 cmd 窗口"留在任务栏(必要代价，也正是独立进程组的体现)。
