用户要求：用户管理后台（user 视角）顶部第二行搜索条最右侧「返回总台」按钮→「返回Web端首页」；账号胶囊菜单「退出登录」上方新增绿色「返回Web端首页」；点击该按钮/菜单项→跳 web(5173) 首页**保持登录态**；点击「退出登录」→跳 web(5173) 首页**未登录态**。

### 关键约束（跨域登录态桥接）
- 两 app 是不同 origin（5174 / 5173 → localStorage 不共享），且 token key 不同：admin=`h5_admin_token`、web=`access_token`+`user_info`。
- 方案：admin 把当前 JWT(`getToken()`)+用户(`getStoredUser()`) 以 URL 参数 `?token=...&user=<urlencoded JSON>` 带去 web；web 入口消费后写入自身登录态。

### 改动文件
- `apps/admin/src/utility.ts`：新增 `WEB_BASE='http://localhost:5173'` 常量。
- `apps/admin/src/components/layout/ObjectScopeBar.tsx`：按钮文案「返回总台」→「返回Web端首页」；onclick 改为 `goWebHome()`（同文件内 helper：拼 token/user 参数后 `window.location.href = WEB_BASE + '/?' + params`）；移除不再使用的 `setView` 解构。
- `apps/admin/src/components/layout/AccountPill.tsx`：
  - 引入 `getToken, WEB_BASE`（已有 `getStoredUser`）。
  - `accountCssVars` 增 `--up: T.up`（绿色 token，供新菜单项用）。
  - 新增 `goWebHome()`（带 token/user 跳 web，保持登录）；`logout()` 改 `authProvider.logout()` 后 `window.location.href = WEB_BASE`（不带 token → web 未登录）。
  - 底部 `.ap-footer` 在「退出登录」上方插入 `<button class="ap-webhome" onClick={goWebHome}>返回Web端首页</button>`。
- `apps/admin/src/styles/account-panel.css`：新增 `.ap-webhome`（绿底绿字按钮，hover 填充 `--up`）—— 仅用 var(--*) 不硬编码色值。
- `apps/web/src/bootstrap.ts`（新建）：读取 `?token`/`?user` 写入 `access_token`/`user_info`，并 `history.replaceState` 清掉 URL 参数；**必须在 App 之前执行**。
- `apps/web/src/main.tsx`：首行 `import './bootstrap';`（先于 `import App`）。

### 验证
- admin + web `pnpm -F ... run typecheck` 均 0 错误。
- Playwright E2E（chromium-1228 + 绝对 playwright 路径）全绿：
