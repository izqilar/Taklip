## 二、新增种子脚本

**`apps/server/prisma/seed-e2e-data.js`**（幂等，可反复运行）

设计要点：
- **幂等**：所有记录使用固定 id；`upsertUser` 在手机号冲突时接管既有账号而非新建。
- **确定性**：固定种子（mulberry32）生成订单，每次运行结果一致，趋势图可复现。
- **对齐服务端聚合口径**：订单跨 30 天分布（`trend14d` 需要）、买家分布多区域（`regionBars` 需要）、代理商与用户挂在同一 `regionPath` 前缀链上（`agentTop` 与 `DataScopeInterceptor` 需要）。

### 2. `GET /api/user/providers` 永远返回空（代码缺陷）

```js
// 问题：拿 templateId 去 User 表匹配 id，永远查不到
const tplIds = orders.map(o => o.templateId);
prisma.user.findMany({ where: { id: { in: tplIds } } })

// 修复：经 templateId → authorId 一跳
const authors = await prisma.template.findMany({
  where: { id: { in: tplIds } }, select: { authorId: true },
});
prisma.user.findMany({ where: { id: { in: providerIds } } })
```

修复前后对比（演示用户 13900001001）：`items: []` → 返回 3 家服务商。

> 这个缺陷此前无人发现，因为演示用户只有 1 笔订单且「我的服务商」面板本就常空。补数据后才暴露。
