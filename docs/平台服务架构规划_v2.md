# 平台服务架构规划 v2（融合优化版）

> 融合来源：① 本方 v1（统一角色后缀 + 功能模块拆解）；② DeepSeek 方案（导航骨架 + 场景化分类 + 生动对外命名 + 服务商入驻流程）
> 核心策略：**双层命名体系**——对外用营销名（C 端好记），对系统内用角色名（开发/数据一致）

---

## 一、平台定位与底层分类原则

定位：以「在线设计」为入口的 **活动与庆典一站式服务平台**。

底层分类依据（来自 DeepSeek，已采纳为全局原则）：
- **物**（工具 / 商品）：设计工坊、鲜花礼品等可标准化交付的内容
- **人**（才艺 / 服务）：设计师、摄影、礼仪、演艺等人力服务
- **场**（空间 / 物流）：宴会场地、同城配送等空间与履约能力

该原则保证后续功能扩展与运营分类逻辑统一。

## 三、六大服务商功能划分（采用对外展示名）

### 1. 特约设计（design_provider）
- 核心功能：模板上架 · 定制接单（接单广场）· 作品集 · 风格标签（中式/西式/简约/卡通）· 交付修改流 · 授权与版权
- 子类目：请柬设计 / 海报设计 / 品牌 VI / 插画
- 入口联动：设计工坊「定制需求」页直接导流至特约设计接单

### 2. 光影纪录（photo_provider）
- 核心功能：拍摄套系上架 · 档期预约 · 客片（样片）展示 · 后期修图 · 成片交付
- 子类目：婚礼跟拍 / 活动摄影 / 产品摄影 / 视频拍摄

### 3. 宴会场地（venue_provider）
- 核心功能：场地展示（容量/风格/配套）· 档期查询与预定 · 套餐管理（餐标/桌餐/自助）· VR 看场 · 合同与定金 · 余位管理
- 子类目：婚宴酒店 / 会议中心 / 生日宴 / 团建基地

### 4. 花艺礼赠（floral_provider）
- 核心功能：花艺上架 · 同城配送范围与时效 · 定制布置（婚礼/桌花）· 礼品组合 · 节日预售 · 贺卡代写
- 子类目：鲜花花束 / 婚礼花艺 / 绿植 / 礼品礼盒

### 5. 仪式执事（ritual_provider）
- 核心功能：服务上架 · 人员资质与形象 · 时长计价（按小时）· 服务区域 · 信任评价体系（敏感场景重点）
- 子类目：婚礼督导/伴郎伴娘 · 丧礼陪伴 · 企业礼仪接待 · 活动司仪 · 气氛组

### 6. 演艺星团（performance_provider）
- 核心功能：节目单/表演样片展示 · 团队阵容与编制 · 档期预约 · 定制编排（婚礼 first dance/年会）· 设备与场地要求 · 报价方案
- 子类目：婚礼乐队 / 舞蹈团 / 歌手 / 主持 / 魔术杂技

## 五、设计与服务的联动闭环（关键转化）

1. **设计工坊 → 定制需求（接单广场）**：用户发布需求，特约设计报价接单（人岗对接）。
2. **设计完成页 → 同款服务推荐**：请柬/海报完成后，页面内插入「同款摄影 / 花艺 / 礼仪 / 演艺」智能推荐，一键预约（把设计流量导给服务商）。
3. **场景页组合曝光**：首页「人生礼仪」等标签页同时展示模板与服务商，提升连带率。

## 六、服务商入驻（B 端触达 · 来自 DeepSeek，已采纳）

### 多路径入口
- 「我的」页面顶部：金色大按钮「我是服务商，立即入驻」
- 「找服务」页右上角：文字链「服务商入驻」
- 首页 Banner / 浮窗：运营活动位（如限时免佣金）
- App 启动页：跳过 / 入驻双选项

### 入驻流程
1. 选择身份（可多选）：设计师/摄影师/宴会厅/花店/演艺团/礼仪执事
2. 填写资质：营业执照（个体户可身份证+经营证明）、服务范围、价格区间
3. 上传作品/样片：至少 3 个案例（图片/视频）
4. 档期设置：摄影/宴会厅/演艺团必须填可服务时间日历
5. 提交审核：1-3 工作日反馈，通过即上架
