# 真实服务商后台 == 管理总台「服务商视角」对齐报告

日期：2026-09-09
目标：让**真实服务商管理后台**（`apps/web` 的 `/provider/*`）与**管理总台里的服务商视角**
（`apps/admin` 的 provider layer）在菜单、页面内容、布局与度量上完全一致。

---

## 一、改造前的差异（根因）

| 维度 | 管理总台 · 服务商视角 | 真实服务商后台（改造前） |
|---|---|---|
| 应用 | `apps/admin`（Refine + antd 5，:5174） | `apps/web`（React + Tailwind H5，:5173） |
| 路由 | `/sp/studio` 等 9 条 | 只有 `/provider/studio`、`/provider/wallet` 两页 |
| 形态 | 240px 侧栏 + 56px 顶栏 + 网格面板 | 顶部 SiteHeader + 模板卡片墙 |
| 主色 | 朱砂 `#c24b2e`（theme.ts） | 微信红 `#c81e42`（tailwind brand-700） |
| 数据 | `provider/dashboard|services|orders|qualification` | 仅 `templates/mine` + `wallet/mine` |

两套技术栈不同，且用户端没有 antd/Refine 依赖 —— 所以采用了「**令牌镜像 + 原生元素复刻**」的方案，
而不是把 antd 装进用户端。

## 九、踩到的坑（已写进技能库）

1. **基线账号必须是服务商本人**：用 ADMIN 登录总台量顶栏会得到 112px（多出四视角切换器 + 监督对象 + 语言），
   用它当基线会把「还原偏差」和「角色差异」混在一起。
2. **Panel 内部也是 `<header>`**：量顶栏高度必须 `[...headers].find(h => !h.closest('section'))`，
   否则量到的是面板头。
3. **空态行高是 2 倍行高**：行高断言要跳过 `colspan` 占位行，否则空表会假失败（92px）。
4. **用户端登录页第一个 button 是语言切换器**：必须 `getByRole('button', { name: /^\s*登\s*录\s*$/ })` 精确定位；
   且要先 `goto('/login')`，默认页未登录时不渲染密码框，会被误判成已登录。
5. **Playwright 依赖只在 apps/admin 能解析**：脚本放 `apps/admin/temp/` 才能 `require('@playwright/test')`。
6. **vite 默认可能只监听 IPv6**：`--host 127.0.0.1` 显式绑定，否则 `curl 127.0.0.1:5173` 拿到 000。
