> 方案定位：***\*原型期 / 内测验证\****使用。音频***\*不得落地进导出文件\****；产品化须切换至 B 方案（官方开放平台授权）。

## 1. 文档目的与适用范围

规范 H5 设计平台中「为作品添加背景音乐」功能在***\*原型期\****接入网易云音乐的技术路径、接口规范、版权合规要求与实施清单，覆盖搜索、试听、编辑、导出灰度全链路。本文档对应总体方案中的 ***\*A 方案（解析接入）\****，用于快速验证产品交互与用户体验，不作为生产环境合规依据。

## 2. 前置约束（版权红线 · 强制）

| 行为                                               | 合规状态                             |
| -------------------------------------------------- | ------------------------------------ |
| 平台内搜索、流媒体试听（不下载 / 不缓存 / 不落地） | ✅ 允许                               |
| 常驻「试听·不可商用」免责提示                      | ✅ 必须                               |
| 将音频复制 / 混音进导出文件再分发                  | ❌ **禁止**（复制传播，免责声明无效） |

***\*核心原则\****：A 方案仅用于「搜得到、听得到」的交互验证；凡涉及作品导出的音频文件，必须来自已授权 / 免费可商用曲库（见 §8、§11）。

## 3. 总体架构（A 方案）

***\*双轨策略\****：搜索与试听走解析接入层；导出 / 落地走独立「已授权曲库」门禁（B 方案接入后开放）。

## 4. 接入方案 A 详解

### 4.1 技术链路（已实测可用）

1. ***\*搜索\****：关键词（如「维吾尔」「木卡姆」「歌手名」）→ 候选列表（曲名 / 歌手 / 封面 / 时长）；
2. ***\*元数据 / 直链\****：以歌曲 `id` 调解析接口，返回 `name / artist / cover / url`；
3. ***\*最终音频\****：`type=url&id=<id>` → ***\*302 跳转\****至网易云 CDN `.mp3`（***\*带时间戳与 token，限时有效\****）；
4. ***\*播放\****：`<audio>` 加载直链试听，播放时实时解析，***\*禁止写死缓存\****。

### 4.2 MetingAPI 接口规范（实测）

基础地址：`https://api.injahow.cn/meting/`

| 能力       | 请求                                                  | 返回 / 说明                     |
| ---------- | ----------------------------------------------------- | ------------------------------- |
| 搜索       | `GET /meting/?server=netease&type=name&name=<关键词>` | 候选歌曲数组                    |
| 单曲元数据 | `GET /meting/?server=netease&type=song&id=<id>`       | `{name, artist, url, pic, lrc}` |
| 音频直链   | `GET /meting/?server=netease&type=url&id=<id>`        | **302 →** CDN `*.mp3`（限时）   |
| 封面       | `GET /meting/?server=netease&type=pic&id=<id>`        | 封面图 URL                      |
| 歌词       | `GET /meting/?server=netease&type=lrc&id=<id>`        | LRC 文本                        |

> ⚠️ 解析服务为第三方公共服务，可能限流 / 宕机 / 被封；直链带时效，***\*每次播放前实时解析\****。

### 4.3 音频时效处理

- 直链 URL 含路径时间戳与 `vuutv` token，通常数小时内失效；
- 前端：播放前动态请求 `type=url` 获取最新直链，失败则提示「资源暂不可用」；
- 后端（推荐）：由服务端代理解析并做短时缓存（TTL < 直链有效期），避免前端暴露与频率过高。

## 5. 功能模块设计

1. ***\*音乐搜索\****：关键词输入 → 防抖请求 → 结果列表（曲名 / 歌手 / 封面 / 时长 / 试听按钮）；
2. ***\*试听播放\****：`<audio>` 播放解析直链，支持播放 / 暂停 / 进度；
3. ***\*免责提示组件（核心）\****：常驻提示条，文案见 §7；
4. ***\*背景音乐编辑\****：插入时间点、裁剪区间、音量、淡入淡出；
5. ***\*导出门禁\****：检测曲目 `licenseStatus`，未授权则禁用「导出 / 混音」，引导付费或替换。

## 6. 数据模型与状态机

```
type Track = {
  id: string;                 // 网易云歌曲 id
  name: string;
  artist: string;
  coverUrl: string;
  duration: number;           // 秒
  source: 'netease';
  audioUrl?: string;          // 运行时解析，不持久化
  expiresAt?: number;         // 直链失效时间
  licenseStatus: 'trial';     // A 方案下恒为 trial
};

type ProjectBGM = {
  projectId: string;
  trackId: string;
  startTime: number;
  volume: number;             // 0~1
  fadeIn?: number;
  fadeOut?: number;
  licenseStatus: 'trial';
};
```

***\*状态机（A 方案）\****：曲目恒为 `trial` → 导出被阻断；产品化经 B 方案授权后转为 `licensed` 方可导出。

## 7. 版权合规实施（强制 · 核心）

- [ ] 所有网易云曲目默认 `licenseStatus='trial'`，UI 标注「试听·不可商用」标识；
- [ ] 免责提示文案（常驻）：
  \> ⚠️ 当前背景音乐由网易云音乐提供***\*试听\****，仅供个人体验，***\*不可商用\****。如用于正式作品，请先开通正版授权后再使用。
- [ ] 导出 / 混音功能对 `trial` 曲目***\*硬阻断\****，并引导「去授权 / 替换免费曲库」；
- [ ] 提供「正版授权说明」入口，说明产品化路径；
- [ ] 原型期结束、进入产品化前，移除 MetingAPI 依赖，切换官方开放平台（§11）。

## 8. 导出灰度与门禁

- 导出按钮对含 `trial` 曲目的作品***\*置灰 / 拦截\****，弹窗提示合规要求；
- 仅当作品背景音乐全部来自「已授权曲库」时开放导出；
- 导出产物（预览包）内附带授权声明，避免用户误用。

## 9. 实施清单（A 方案）

## 10. 风险与兜底

| 风险                  | 应对                                            |
| --------------------- | ----------------------------------------------- |
| 解析服务不稳定 / 限流 | 失败重试 + 兜底提示「暂不可用」；服务端代理降频 |
| 直链失效              | 播放前实时解析；过期自动重新获取                |
| 用户误导出 trial 音频 | 门禁硬阻断 + 合规弹窗                           |
| 版权投诉              | 仅试听不落地；保留免责提示与授权入口            |

## 11. 向 B 方案（产品化）迁移路径

1. 入驻网易云开放平台 `developer.music.163.com`，企业资质 + 审核 + AppID；
2. 以官方搜索 / 歌曲 / 歌词接口替换 MetingAPI；
3. 播放走平台授权播放能力（不落地），商用分发签授权协议（有偿）；
4. 曲目 `licenseStatus` 支持 `licensed`，开放导出门禁；
5. 移除第三方解析依赖，完成合规闭环。
