# 分层后台 · 详情对话框系统性规划（v1 待协商稿）

> 范围：总台 10 页 + 代理商 5 页 + 服务商 4 页（共 19 个带操作列页面）。
> 用户视角 6 页已定制完成，本次仅复核。
> 本稿只做功能与内容规划，不做开发。逐条敲定后进入开发。

---

## 〇、设计原则

| 操作类型 | 适用页面 | 对话框形态 |
|---|---|---|
| **A 仅查看** | 监督型（辖区用户） | 只读详情，无写操作 |
| **B 查看 + 审核** | 审核型（入驻/模板/提现/公告/初审复审/业务升级） | 查看详情 + 「通过 / 驳回(必填原因)」 |
| **C 查看 + 编辑** | 可写型（区域/代理/用户/反馈/角色/服务/资质/配置） | 查看详情 + 「编辑」进入表单 |
| **D 仅编辑** | 配置型（系统设置） | 点开即表单，不另设只读查看 |

- 详情对话框字段 = 该页数据列全集 + 业务必需补充字段（电话/余额/正文/资质材料等）。
- 审核动作：通过 / 驳回（驳回需填原因，必填校验）。
- 编辑动作：保存后即时反映到列表状态。
- 总台可代操作（可写权限）；代理/服务商/用户视角默认只读，仅总台超级管理员授权后才可写。

## 一、总台（10 页）

### 1. 区域管理 `regions` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：区域名称、级别（省级/市级/区县级）、上级区域、绑定代理商、服务商数、用户数、月流水
- **编辑字段**：区域名称、级别、上级区域、绑定代理商（下拉）＋ 保存/取消

### 2. 代理商管理 `agents` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：代理商名称、所属辖区、服务商数、用户数、月流水、状态、入驻时间、联系电话
- **编辑字段**：代理商名称、绑定辖区、状态（正常/待复核/停用）、备注 ＋ 保存/取消

### 3. 服务商管理（入驻审核）`review` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过 / 驳回
- **查看详情字段**：申请人、手机号、服务类型、所属区域、资质材料（营业执照/实名认证/案例集）、提交时间、申请状态
- **审核动作**：通过（一键上架）/ 驳回（必填驳回原因）

### 4. 用户管理 `users` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：用户（昵称）、手机号、角色、所属区域、注册时间、状态、消费等级
- **编辑字段**：角色（客户/服务商/代理商/管理员）、所属区域、状态（正常/停用）、备注 ＋ 保存/取消

### 5. 模板审核 `templates` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过 / 驳回
- **查看详情字段**：模板名称、作者、类型、价格、模板封面/预览、状态
- **审核动作**：通过（上架）/ 驳回（必填原因）；已上架模板可下架

### 6. 提现审核 `withdrawals` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过 / 驳回
- **查看详情字段**：服务商、申请金额、收款账户（开户行/卡号）、申请时间、当前可用余额、状态
- **审核动作**：通过（进入打款）/ 驳回（必填原因）

### 7. 评价与反馈中心 `feedback` — 操作类型 C（查看+处理）
- **按钮**：查看 / 处理
- **查看详情字段**：编号、类型、反馈人、对象、反馈内容、状态、时间
- **处理动作**：协商意见、状态流转（协商中→已关闭）、可升级总台仲裁

### 8. 消息中心 `messages` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过（发布）/ 驳回
- **查看详情字段**：标题、类型、接收范围、正文内容、状态、发布时间
- **审核动作**：通过（发布）/ 驳回（必填原因）

### 9. 角色与权限 `roles` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：角色名称、归属层级、账号数、数据作用域、功能权限、权限位阶、类型
- **编辑字段**：新建/修改角色（角色名称、数据作用域、功能权限勾选、成员分配）＋ 保存/取消

### 10. 系统设置 `settings` — 操作类型 D（仅编辑）
- **按钮**：编辑
- **编辑表单字段**：分类、配置项、当前值（可改）、说明 ＋ 保存/取消（不设只读查看）

## 二、代理商中心（5 页）

### 11. 辖区用户 `a-users` — 操作类型 A（仅查看）
- **按钮**：查看
- **查看详情字段**：用户、手机号、角色、所属辖区、注册时间、状态、消费等级
- **说明**：代理商对用户为监督角色，不提供编辑（用户资料变更权在用户本人与总台）；「待复核」用户仅展示标记。

### 12. 辖区服务商 `a-providers` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过 / 驳回
- **查看详情字段**：服务商、服务类型、资质、本月接单、状态、联系电话、入驻时间
- **审核动作**：按状态对应——初审通过/驳回、复审通过/驳回、业务升级审核通过/驳回（驳回必填原因）

### 13. 辖区评价与反馈 `a-feedback` — 操作类型 C（查看+处理）
- **按钮**：查看 / 处理
- **查看详情字段**：编号、类型、用户、对象、反馈内容、状态、时间
- **处理动作**：协商结论、标记已处理、超时升级总台

### 14. 辖区消息中心 `a-messages` — 操作类型 B（查看+审核）
- **按钮**：查看 / 通过（发布）/ 驳回
- **查看详情字段**：标题、类型、正文内容、状态、时间
- **审核动作**：通过（发布辖区公告）/ 驳回（必填原因）

### 15. 辖区角色与权限 `a-roles` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：角色名称、归属层级、账号数、数据作用域、功能权限、类型
- **编辑字段**：新建/修改辖区自定义角色（名称、数据作用域 REGION、功能权限勾选、成员分配）

## 三、服务商中心（4 页）

### 16. 服务管理 `p-services` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：服务名称、类型、价格、状态、销量、上架时间
- **编辑字段**：服务名称、类型、价格、状态（上架/下架）、服务描述 ＋ 保存/取消

### 17. 资质管理 `p-qualification` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：资质项、编号、有效期、审核状态、审核时间
- **编辑动作**：补充/更新材料、重新提交审核

### 18. 服务评价与反馈 `p-feedback` — 操作类型 C（查看+处理）
- **按钮**：查看 / 处理
- **查看详情字段**：编号、类型、对象、反馈内容、状态、时间
- **处理动作**：回应说明、发起申诉

### 19. 服务角色与权限 `p-roles` — 操作类型 C（查看+编辑）
- **按钮**：查看 / 编辑
- **查看详情字段**：角色名称、归属层级、账号数、数据作用域、功能权限、类型
- **编辑字段**：新建/修改服务自定义角色（名称、数据作用域 SELF、功能权限勾选、成员分配）

## 五、确认的决策点

1. **辖区用户（11）**：仅查看、无编辑
2. **系统设置（10）**：仅编辑、无只读查看
3. **消息中心（8、14）**：按钮语义为「查看 + 通过(发布)/驳回」，而非「编辑」
4. **审核类驳回**：「驳回原因必填」为统一规则
5. **反馈类处理（7、13、18）**：操作为「查看 + 处理(意见/流转)」，而非「编辑」
6. **用户管理（4）**：总台可改「角色/区域/状态」，不涉用户资料（昵称/手机号）
7. **19 页详情字段**：各页字段是按上表确认。

## 六、功能权限复选框组设计（角色与权限 · 2026-08-28 定稿）

> 背景：原「角色详情」编辑对话框的「功能权限」为自由文本框，无法精确表达权限边界。
> 决策：改造为「功能域 × 操作」的权限点复选框组；勾选结果作为权限配置核心，替代自由文本。

### 6.1 权限点清单（10 个功能域）

| # | 功能域 | 权限点复选框 |
|---|---|---|
| ① | 用户与账号 | 用户查询 / 用户编辑（角色·状态·启停） |
| ② | 入驻与服务商 | 入驻审核 / 资质审核 / 业务升级审核 |
| ③ | 服务与内容 | 模板/服务上架 / 内容下架 / 模板审核 |
| ④ | 订单与履约 | 订单查询 / 订单处理（接单·履约·交付）/ 售后处理 |
| ⑤ | 财务 | 流水查询 / 提现审核 / 提现代操作 / 对账 |
| ⑥ | 优惠券与权益 | 券/权益配置 / 优惠券发放 / 权益查询 |
| ⑦ | 评价与申诉 | 反馈处理 / 申诉仲裁 |
| ⑧ | 消息与公告 | 公告发布 / 公告审核 / 站内信收发 |
| ⑨ | 组织与系统 | 角色管理（创建/授权）/ 区域·代理商管理 / 系统设置 |
| ⑩ | 数据导出 | 列表数据导出（用户/订单/流水/评价等全列表通用） |

### 6.2 设计原则

1. **域内操作分级**：只设「查看 / 处理（含审核）」两档操作粒度，不拆到增删改查过细，避免权限矩阵爆炸。
2. **敏感权限独立**：⑨「系统设置」「角色管理」、⑤「提现代操作」三处最敏感点单独成框，与普通权限分开勾选，强化授权边界（呼应"运维管理员默认只读、授权可写"）。
3. **导出统一授权**：⑩为横向统一权限点，勾选后各列表页「导出」可用；如需按域控制（如只导订单不导用户）可后续升级为域级导出。
4. **三层复用同构**：总台/代理商/服务商共用同一套权限点结构，各层仅展示自己管辖范围内的域。

### 6.3 三层功能域映射

- **总台**：①~⑩ 全 10 域
- **代理商**：①②④⑤⑥⑦⑧⑨⑩（③服务上架、系统设置等总台专属项不展示；显示管辖范围内子集）
- **服务商**：③④⑤⑦⑧⑩ + 自身资质/财务（不含 ①用户、②入驻审核、⑥券权益、⑨组织管理）

### 6.4 现有角色映射示例（总台）

| 角色 | 勾选权限点 |
|---|---|
| 超级管理员 | ①~⑩ 全勾 |
| 运维管理员 | 查询类全勾 + 反馈处理 + 列表数据导出（默认只读、授权可写部分模块） |
| 服务审核员 | 入驻/资质/业务升级审核 + 模板审核 + 反馈处理 + 申诉仲裁 + 公告审核 + 列表导出 |
| 财务管理员 | 流水查询 + 提现审核 + 提现代操作 + 对账 + 权益查询 + 列表导出 |
| 在线客服 | 站内信收发 + 用户查询 + 订单查询 + 反馈处理（仅查询回复） |
| 代理商 | 用户查询 + 订单查询/处理 + 反馈处理 + 申诉仲裁 + 站内信收发 + 列表导出 |
| 服务商 | 订单查询/处理 + 售后处理 + 资质审核 + 站内信收发 + 列表导出 |
| 辖区活动专员 | 优惠券发放 + 权益查询 + 反馈处理 + 列表导出（营销执行） |

### 6.5 数据落地

- 每角色记录增加**隐藏权限点数组字段**（列表列仍展示原功能权限概要文本）。
- 编辑对话框按角色已勾选点位回显；保存后写回权限点数组。
- 新建角色时数组为空（全不勾选），由创建者按需勾选。
