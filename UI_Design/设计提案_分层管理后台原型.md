# 庆柬云 · 分层管理后台原型 — 设计方案

> 交付物：可运行原型 `index.html`（单文件，内联 CSS/JS/SVG，无外部依赖，浏览器直接打开）
> 设计原则：**一个后端 · 分层治理 · 总台统筹**

---

## 一、分层登录模型（本次落地）

| 层 | 菜单 | 作用域 | 首页 |
|---|---|---|---|
| 管理总台 ADMIN | 13 项（超集） | ALL | 经营总览 |
| 代理商中心 AGENT | 7 项 | REGION（辖区） | 辖区概览 |
| 服务商中心 SP | 7 项 | SELF（自身） | 我的工作台 |
| **用户视角 USER** | **7 项** | **SELF（单用户）** | **用户工作台** |

- 登录即定层：菜单 = 该层作用域投影，低层看不到高层入口；
- **方案 B**：总台侧边栏只放 13 项治理菜单，通过**页头「角色视角」切换**进入代理商/服务商视角（所见即所得，而非三层并排 26 项）；
- 三层各有独立首页，登录/切换后自动落位。

## 二、三项决策的原型落点

1. **总台 13 项 + 页头视角切换**：`总台视角 / 代理商视角 / 服务商视角` segmented 控件，切换后侧栏菜单、面包屑、首页、数据作用域整体联动。
2. **可写 / 只读按管理员账号**：页头账号菜单可在「超级管理员（可写·可代操作）」与「运维管理员（只读·默认只读，单独授权可写）」间切换；只读时顶部出现黄色提示条、主操作按钮禁用、行内通过/驳回/编辑锁定。
3. **服务商入驻审核进总台队列**：`服务商管理` 页内置「入驻审核队列」，总台统一把关（本期已切换），待审计数 12 直达。

## 二·B、具体对象视角（View-As，本轮新增）

管理员切到**代理商视角 / 服务商视角**时，页头下方出现**「对象视角」工具栏**：
- 搜索框按 **ID / 用户名 / 昵称 / 手机号 / 区域** 模糊检索并下拉选择某个**具体**代理商或服务商；
- 选中后整页数据（首页 KPI、待办、辖区服务商/我的服务/最近订单）**整体切换到该对象名下**，面包屑、作用域标签、页题同步更新；
- 工具栏常显当前对象身份（如 `艾山江 · 沙依巴克区 · 139****7756`）与「以「XX」代理商身份查看 · 数据仅限该对象」提示，可一键**返回总台**；
- 写权限仍遵循决策②：超级管理员＝可写（可在该对象范围内代操作），运维管理员＝只读核查；
- 作用域隔离由后端 `regionPath / 所属服务商` 强制，原型为前端演示数据。

## 三、总台 13 项菜单（最终定稿）

```
管理总台
├─ 总览与治理：经营总览 / 区域管理 / 代理商管理 / 服务商管理（含入驻审核队列）
├─ 运营监管：用户管理 / 模板审核 / 订单管理
├─ 财务中心：钱包总览 / 提现审核（待办 3）
├─ 评价与反馈中心（全部反馈 + 升级仲裁，两段合一）
├─ 消息中心（收件箱 + 权威公告审核，两段合一）
└─ 系统：角色与权限 / 系统设置
```

关键改动：原 12 个平级项 → 6 个顶级入口；「升级反馈仲裁」「权威公告审核」并入各自中心页内 Tab；补齐「模板审核」「角色与权限」。

## 四、代理商 / 服务商菜单（7 项，与定稿一致）

- **代理商中心**：辖区概览 / 辖区用户 / 辖区服务商 / 辖区订单 / 结算与钱包 / 评价与反馈中心 / 消息中心
- **服务商中心**：我的工作台 / 服务管理 / 订单处理 / 资质管理 / 钱包与提现 / 评价与反馈中心 / 消息中心
- **用户中心（用户视角）**：用户工作台 / 我的订单 / 我的服务商 / 优惠与权益 / 我的钱包 / 评价与反馈 / 消息中心

## 五·B、用户视角（观察/调整用户 + 会员等级测试）

管理员在「用户视角」下以**具体用户**身份查看其个人中心（对象选择器按 ID/昵称/手机号/城市检索）：
- **用户工作台**：资料卡（头像/姓名/等级/ID/手机/城市/注册时间）+ 账户余额 / 积分 / 进行中订单 / 累计消费 + 我的订单 + 会员权益 + 关注服务商 + 优惠券 + 我的评价；
- **会员等级测试台**：一键在 普通 / 银卡 / 金卡 / 黑金 之间切换，预览该等级「可享权益」（折扣、优先排期、金牌管家等）与页面表现，用于**功能与服务测试**；
- **调整用户数据**：弹窗调整 会员等级 / 余额 / 积分 / 调整类型（客服补偿·等级复核·功能测试·人工修正），带留痕说明；超级管理员可写，运维管理员只读锁定；
- **六个子模块全部落地**（按当前选中用户动态渲染，切换用户即联动刷新）：我的订单（订单/服务/服务商/金额/时间/状态）、我的服务商（类型/评分/关注时间）、优惠与权益（面额/有效期/使用条件）、我的钱包（充值·消费·退款·积分兑换流水/变动后余额）、评价与反馈（评分/评价内容/时间）、消息中心（订单·权益·服务通知/已读未读）；行内「查看」弹出按模块定制字段的详情弹窗；
- 等级与权益变化会同步到该用户的会员标签、权益卡与测试开关高亮。

## 五、设计系统

- **底色**：暖石微染（非纯白，长时盯屏友好）
- **强调色**：朱砂 `#c24b2e`（庆柬品牌·喜庆红绸）单角色，仅用于当前导航 / 主操作 / 主指标
- **副色**：青 `#14676b`（冷暖对，服务商/合作语义）
- **状态双角色**：成功绿 / 警示琥珀 / 危险品红，浅底 + 深字（过 WCAG）
- **字阶**：KPI 27px / 页题 18px / 正文 14px / 表头 12.5px，数字 tabular
- **圆角**：卡片 10px / 控件 6px / 胶囊 999px（只有可点的才圆）
- **动效**：静默（切换/弹窗 180ms 过渡，无花哨）

## 六、B 端四态（已全量实现）

有数据（KPI+图表+表格+待办）／ 空状态（给出口按钮）／ 加载态（骨架屏）／ 异常态（说明+重试）

## 七、原型已实现的可交互能力

- 视角切换（总台/代理商/服务商）→ 菜单+首页+数据联动
- 13+7+7 全部菜单项可点，均落到真实列表页（含筛选、搜索、分页、导出）
- 审核弹窗按行填充数据，通过/驳回随只读态锁定
- 待办项点按直达对应队列
- 账号菜单切换可写/只读
