# 请柬云 · 四层角色菜单架构评估与优化方案

> 编制日期：2026-09-06 ｜ 状态：待拍板
> 优化目标：**管理总台 = 四层功能超集 + 全局治理 + 分层视角代查代操作**；代理商 / 服务商 / 用户层在不推翻现有框架的前提下补齐业务闭环。

---

## 一、现状诊断

### 1. 管理总台（问题最集中，需深度重构）

| # | 位置 | 问题 | 影响 |
|---|------|------|------|
| 1 | 数据看板 → 代理商信息 / 服务商信息 / 用户信息 | 「信息」不是看板项，与后文「代理商管理 / 服务商管理 / 用户管理」功能重叠、边界模糊 | 入口重复、语义混乱 |
| 2 | 代理商中心 / 服务商中心 → 入住审批 | 错别字：应为「**入驻**审批」 | 命名不规范 |
| 3 | 系统设置 → 财务总览 | 财务属于业务域，混入系统设置分组 | 分组语义错误 |
| 4 | 业务中心 → 模版审核 | 错别字：应为「**模板**审核」 | 命名不规范 |
| 5 | 全菜单 | 缺：订单管理、财务中心（资金流水 / 结算）、优惠券 / 权益管理、公告管理、审计日志、角色与权限 | 治理功能不完整，达不到管理后台标准 |
| 6 | 全菜单 | 未体现总台「以四层角色视角查看 / 操作」的能力入口（UI 已有视角切换，菜单层无呼应） | 总台核心价值没有显性化 |
| 7 | 用户中心 | 仅「用户管理 / 用户订单」两项，结构过轻 | 分组不平衡 |

### 2. 代理商中心（轻度优化）

| # | 位置 | 问题 | 建议 |
|---|------|------|------|
| 1 | 数据看板 → 辖区用户 / 辖区订单 | 业务列表混入看板分组 | 移入「辖区运营」分组，看板只留「辖区经营概览」 |
| 2 | 分组名「服务商中心」 | 代理商层叫「服务商中心」与其管辖身份不符 | 改名「**辖区服务商**」，突出辖区属性 |
| 3 | 缺招商拓展 | 代理商核心业务是拓展辖区服务商，菜单无入口 | 新增「招商拓展」分组（招商申请 / 意向池） |
| 4 | 系统设置 → 财务总览 | 代理商的财务本质是「佣金分账」，不叫财务总览 | 新增「财务中心」分组（结算总览 / 提现初审） |

### 3. 服务商中心（轻度优化）

| # | 位置 | 问题 | 建议 |
|---|------|------|------|
| 1 | 缺「订单履约」 | 服务商核心业务是接单履约，菜单完全没有订单处理入口 | **必补**：新增「订单履约」分组（我的订单：待接单 / 履约中 / 已完成 / 售后） |
| 2 | 数据看板 → 我的用户 / 我的订单 | 业务列表混入看板 | 移出；「我的用户」改名「我的客户」（C 端心智） |
| 3 | 团队中心 → 我的团队 / 我的钱包 / 账户详情 | 组织、财务、设置三类语义硬凑一组 | 拆散：钱包 → 财务中心；账户详情 → 系统设置 |
| 4 | 财务仅「我的钱包」 | 缺收入明细 / 提现 / 结算单 | 新增「财务中心」（收入明细 / 提现管理 / 我的钱包） |

### 4. 用户中心（轻度优化）

| # | 位置 | 问题 | 建议 |
|---|------|------|------|
| 1 | 消息中心 → 我的评价 / 我的反馈 | 评价与反馈是用户内容，不是消息 | 移出，独立「评价与反馈」分组 |
| 2 | 交易中心 → 我的工作台 | 工作台是聚合首页，语义上不属于交易 | 保持交易中心内置于首位（作为默认落地页） |
| 3 | 整体 | 已基本定型，结构合理 | 仅做上述轻量调整 |

## 二、优化设计原则（优秀管理后台标准）

1. **按「域」组织，而非按「对象」堆叠**：数据看板 / 业务域 / 财务域 / 内容域 / 消息域 / 系统域，分组语义互斥、不重不漏。
2. **看板只放聚合页**：任何「列表 / 管理 / 审批」都归业务分组，看板分组只保留 1 个概览页。
3. **财务独立成域**：钱的事单独成组，不再混入系统设置或团队中心。
4. **命名规范统一**：入驻（非入住）、模板（非模版）、资质（非资格）——「资格」指入驻主体资格，「资质」指业务证照，两词分工。
5. **四层骨架一致**：数据看板 → 业务 → 财务 → 消息 → 系统设置，各层按权限裁剪，用户能一眼看懂「我在哪层、能做什么」。
6. **总台显性化视角能力**：总台菜单保持全局超集，顶部视角切换 + 各主体页「进入 XX 视角」双入口，落实「总台可代查代操作」。

## 三、优化后的四层菜单（完整树）

### 管理总台（核心重构，8 组 27 项）

```
管理总台
├─ 数据看板
│   └─ 经营总览（全局大盘：交易 / 用户 / 主体 / 财务 四维卡片 + 视角入口）
├─ 主体中心（折叠组，统管三大主体）
│   ├─ 代理商中心（折叠子组）
│   │   ├─ 代理商管理          ｜ 入驻审批（新增→初审→终审）
│   │   ├─ 资格审核            ｜ 合同管理
│   │   └─ 考核与分佣
│   ├─ 服务商中心（折叠子组）
│   │   ├─ 服务商管理          ｜ 入驻审批
│   │   ├─ 资质审核            ｜ 合同管理
│   │   └─ 服务监管（辖区服务上架审核）
│   └─ 用户中心（折叠子组）
│       ├─ 用户管理            ｜ 用户订单
│       └─ 用户反馈（含投诉 / 举报）
├─ 业务中心
│   ├─ 模板审核（模板上下架）
│   ├─ 订单管理（全平台订单总览 / 异常订单）
│   ├─ 服务评价
│   └─ 意见反馈
├─ 财务中心
│   ├─ 财务总览（资金流水 / 收支结构）
│   ├─ 提现审核
│   └─ 结算管理（主体结算单 / 分佣）
├─ 内容与营销
│   ├─ 公告管理（全局公告发布与审核）
│   └─ 券与权益（优惠券 / 会员权益配置）
├─ 消息中心
│   ├─ 通知公告（总台发布 + 审核）
│   └─ 业务消息（全平台业务消息）
└─ 系统管理
    ├─ 角色与权限（总台 5 职能 + 自定义角色）
    ├─ 业务设置（平台参数 / 类目 / 流程配置）
    ├─ 系统设置（基础配置 / 安全策略）
    ├─ 审计日志（操作留痕，安全标配）
    └─ 账户详情
```
