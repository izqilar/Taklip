# 请柬云 · 四层角色菜单（定稿）

> 更新日期：2026-09-06 ｜ 状态：已按《菜单架构优化方案.md》拍板定稿
> 设计原则：同一后端、分层治理、总台统筹；按「域」组织（看板 / 主体 / 业务 / 财务 / 内容 / 消息 / 系统）。

---

## 一、管理总台（全局超集 + 分层视角代查代操作）

### 数据看板

- 经营总览（全局大盘：交易 / 用户 / 主体 / 财务四维卡片 + 视角入口）

### 主体中心（折叠组，统管三大主体）

#### 代理商中心（折叠子组）

- 代理商管理
- 入驻审批（新增→初审→复审→终审→签约）
- 资格审核
- 合同管理
- 考核与分佣

#### 服务商中心（折叠子组）

- 服务商管理（含入驻审核队列）
- 入驻审批
- 资质审核
- 合同管理
- 服务监管（服务上架审核 / 违规下架）

#### 用户中心（折叠子组）

- 用户管理
- 用户订单
- 用户反馈（投诉 / 举报 / 建议）

### 招商管理

- 招商申请（意向代理商报名）
- 意向池（潜在代理商资源池）

### 业务中心

- 区域管理（行政区划树维护）
- 模板审核
- 订单管理（全平台订单总览 / 异常订单）
- 服务评价
- 意见反馈

### 财务中心

- 财务总览（平台资金流水）
- 提现审核
- 结算管理（主体结算单 / 分佣核算）

### 内容与营销

- 公告管理（全局公告发布与上下线）
- 券与权益（优惠券 / 会员权益配置）

### 消息中心

- 通知公告（收件 + 公告审核）
- 业务消息（全平台业务消息流）

### 系统管理

- 角色与权限（总台 5 职能 + 自定义角色）
- 业务设置（业务参数 / 流程规则）
- 系统设置（全局配置）
- 审计日志（操作留痕）
- 账户详情

---

## 二、代理商中心（辖区经营）

### 数据看板

- 辖区经营概览

### 辖区服务商（折叠组）

- 辖区服务商
- 入驻审批（辖区服务商入驻初审 / 复审）
- 资质审核（辖区服务商证照审核）
- 合同管理
- 服务监管（辖区服务上架审核）

### 辖区运营

- 辖区用户
- 辖区订单
- 服务评价
- 意见反馈

### 招商拓展

- 招商申请（辖区服务商招募）
- 意向池（潜在服务商资源池）

### 财务中心

- 结算总览（佣金 / 分佣明细）
- 提现初审（辖区服务商提现初审）

### 消息中心

- 通知公告
- 业务消息

### 系统设置

- 角色与权限（辖区自定义角色）
- 业务设置（辖区业务参数）
- 账户详情

---

## 三、服务商中心（自身履约）

### 数据看板

- 经营概览（订单 / 收入 / 评价汇总）

### 订单履约

- 我的订单（待接单 / 履约中 / 已完成 / 售后）
- 档期管理（排期看板）

### 服务与内容

- 服务管理（上架 / 下架 / 定价）
- 模板发布
- 我的评价（客户评价）
- 意见反馈（向平台反馈 / 申诉）

### 资质中心

- 业务申请（入驻 / 业务新增 / 业务升级）
- 资质管理（证照维护 / 到期提醒）
- 合同管理

### 财务中心

- 收入明细（入账 / 挂账 / 出账）
- 提现管理
- 我的钱包

### 消息中心

- 通知公告
- 业务消息

### 团队与设置

- 我的团队（成员 / 角色分工）
- 我的客户（客户档案）
- 账户详情

---

## 四、用户中心（个人交易）

### 交易中心

- 我的工作台（默认落地页）
- 我的服务商（收藏 / 关注 / 历史）
- 我的订单（待付款 / 进行中 / 已完成 / 售后）

### 评价与反馈

- 我的评价（我发布的评价）
- 我的反馈（我的投诉 / 建议）

### 消息中心

- 通知公告
- 业务消息

### 个人中心

- 我的钱包
- 优惠与权益
- 账户详情
