# 文档说明

本文档由已通过验收的分层管理后台 UI 原型提炼而成，作为后端与前端开发团队实现「庆柬云」B 端管理系统的完整契约。读者：产品负责人、前后端工程师。范围：总体架构、角色权限、菜单与页面规格、详情对话框、数据模型、交互规则、设计系统与后端落地建议。

术语：总台（ADMIN 管理总台）、代理商（AGENT）、服务商（SP）、用户（USER）；「视角」指管理员在总台侧通过页头切换进入某一角色层的工作界面；「对象视角」指在某角色层内检索并切换到某一个具体代理商 / 服务商 / 用户，查看其名下数据。

# 项目概述

## 背景与目标

平台采用「一个后端 · 多角色分层登录」模式：管理总台可全盘管理所有菜单与数据；代理商仅见代理商中心；服务商仅见服务商中心；用户视角用于运营对用户数据的观察、调整与会员等级功能测试。目标：一套后端代码承载四个决策层级，菜单与数据按层级投影，权限不越层。

## 设计原则

1. 一个后端、分层治理、总台统筹：登录即定层，菜单 = 该层作用域投影，低层看不到高层入口。

2. 总台 13 项超集 \+ 页头视角切换：总台侧边栏只放治理菜单，通过「总台 / 代理商 / 服务商 / 用户」视角切换进入各层工作界面。

3. 可写 / 只读按管理员账号：超级管理员可写（总台可代操作）；运维管理员默认只读，单独授权可写。

4. 服务商入驻审核进总台审核队列（admin/providers），总台统一把关。

5. 底层角色权限不得触达高层权限范围：各层仅显示本层权限域。

## 非目标

本文档不包含移动端 C 端设计、支付通道实现、消息推送通道细节；不包含真实鉴权与数据库 DDL（见后端开发建议章节的接口约定）。

# 总体架构

## 分层登录模型

|层|菜单数|数据作用域|首页|
|---|---|---|---|

## 视角切换机制

页头提供「总台视角 / 代理商视角 / 服务商视角 / 用户视角」切换控件（segmented）。切换后侧栏菜单、面包屑、首页、数据作用域、页题整体联动；三层各有独立首页，登录 / 切换后自动落位。

## 可写 / 只读模型

页头账号菜单可在「超级管理员（可写 · 可代操作）」与「运维管理员（只读 · 默认只读，单独授权可写）」间切换。只读时：顶部出现黄色提示条、主操作按钮禁用、行内通过 / 驳回 / 编辑锁定；只读态可查看全部数据。

## 数据隔离

作用域隔离由后端 `regionPath / 所属服务商` 强制：总台见全量；代理商仅见其辖区（regionPath 前缀）；服务商仅见自身服务域；用户视角仅见当前选中用户。原型为前端演示数据，真实实现由后端按当前角色与登录主体返回。

# 角色与权限体系

## 角色类型

总台管理员展开为 5 个职能角色，权限位阶从高到低：超级管理员 → 运维管理员 → 服务审核员 = 财务管理员 → 在线客服。其他决策层可在其管辖范围内设立同类职能角色，并支持创建自定义角色。

- 超级管理员：所有内容可读可写，可创建 / 授权角色。

- 运维管理员：所有内容默认可读，部分内容可写（开通权限）。

- 服务审核员：只读 \+ 处理总台审核类内容（入驻 / 模板 / 公告 / 申诉）。

- 财务管理员：全权处理提现等财务内容（提现 / 钱包 / 流水 / 对账）。

- 在线客服：答复各类问题，除查询回复外无实质业务权限。

## 权限三要素

每条角色记录含：归属层级（总台 / 代理商 / 服务商）× 类型（内置 / 自定义）× 职能，叠加权限三要素：数据作用域（ALL / REGION / SELF）、功能权限（权限点勾选集合）、授权边界（数据 / 功能 / 位阶）。

# 界面框架

## 整体布局

三段式：顶部页头（品牌 \+ 视角切换 \+ 对象选择入口 \+ 账号模式）｜左侧侧栏（按当前视角渲染菜单，含分组与角标）｜主内容区（面包屑 \+ 页题 \+ 筛选/搜索/导出工具条 \+ 数据表 \+ 分页）。

## 页头要素

- 品牌「庆柬云」；当前视角 crumb（管理总台 / 代理商中心 / 服务商中心 / 用户视角）。

- 视角切换 segmented；账号菜单（超级管理员 / 运维管理员，可写 / 只读标签）。

- 代理商 / 服务商 / 用户视角页顶部含「返回总台」按钮，右缘对齐页面 pghead 内角色标签右缘。

## 侧栏导航

按 `MENU[VIEW]` 渲染分组与菜单项，当前项高亮，含待办角标（如入驻审核 12、提现审核 3）。点击项切页；菜单 = 该层作用域投影。

## 对象视角工具栏

管理员切到代理商 / 服务商 / 用户视角时，页头下方出现「搜索」工具栏：按 ID / 用户名 / 昵称 / 手机号 / 区域模糊检索并下拉选择某一具体对象；选中后整页数据（首页 KPI、待办、列表）整体切换到该对象名下，面包屑与作用域标签同步；工具栏常显当前对象身份，可一键返回总台。搜索框支持输入即出下拉候选与「当前」标记。

## 内容区与列表页

列表页由统一引擎渲染：标题 \+ 副标题 \+ 作用域 chip \+ 分类筛选按钮（可点击快速筛选）\+ 关键词搜索框（含「搜索」按钮与悬停清空叉）\+ 导出按钮 \+ 数据表 \+ 总条数 \+ 「＋新建」主操作。操作列按页面类型渲染「查看 / 编辑 / 通过 / 驳回 / 处理」。

# 交互规则

## 审核流程

状态机：待审核 → 已通过 / 已驳回。驳回必填原因；通过写入通过意见。代理商辖区服务商审核含初审 → 待复审 → 已通过，业务升级审核独立成链（服务商业务类型可为多个项目，升级需过代理商审核关卡）。财务提现审核由财务管理员全权处理。

## 编辑保存

查看态显示「编辑」；进入编辑态按钮变为「保存」，同时显示「取消」；保存后权限组合 / 字段写入数据并刷新列表，随后返回查看态。编辑框预填当前记录，杜绝空白表单。

## 搜索 / 筛选 / 导出

- 分类筛选：全部 / 各状态为可点击按钮，点击即检索对应列表，去计数只留名称。

- 关键词搜索：输入框 \+ 独立「搜索」按钮 \+ 回车触发；输入内容后悬停显示清除叉，点击一键清空。

- 导出：列表数据导出为 CSV（受「数据导出」权限点控制）。

- 对象搜索：视角内按 ID / 用户名 / 昵称 / 手机号 / 区域模糊检索并选择具体对象，整页联动。

## 只读锁定

运维管理员默认只读：黄色提示条常驻，主操作（新建 / 通过 / 驳回 / 编辑 / 调整用户数据）全部禁用，仅保留查看与导出。

## 待办直达

首页待办卡片（入驻审核 / 提现 / 评价等）点击直达对应列表页；侧栏角标实时反映待办计数。

# 后端开发建议

## 接口与数据模型落地

- 四层登录：登录接口返回账号角色与所属层级；前端据此渲染对应菜单与作用域。

- 列表接口：page key → 后端返回标题 / 列定义 / 行数据 / 筛选与计数；搜索、筛选、导出为公共参数。

- 审核接口：POST 通过 / 驳回（驳回原因必填），服务端做状态机校验与幂等。

- 对象视角接口：按代理商 / 服务商 / 用户 ID 返回该对象整页聚合数据（KPI \+ 列表）。

- 角色权限接口：角色 CRUD \+ 权限点数组存取；不同层级角色数据相互隔离。

## 权限控制落地

RBAC \+ 位阶校验：功能权限按 10 域 28 点配置到角色；接口层拦截「数据作用域 × 功能权限 × 位阶」三维校验；超级管理员最高，运维管理员只读 \+ 授权写，服务审核员仅审核域，财务管理员仅财务域，在线客服仅查询回复；自定义角色由各层负责人按管辖范围创建并限定在其数据域内。

## 数据隔离落地

区域表含 regionPath（如 乌鲁木齐 / 天山区）；代理商绑定辖区；服务商挂所属区域与服务类型；订单 / 反馈 / 消息关联主体。后端以当前登录主体推导可见域，任何接口不可越层取数。

## 验收清单

1. 四层登录与菜单投影正确，总台 13 项可见全量，低层无高层入口。

2. 视角切换后侧栏 / 面包屑 / 首页 / 数据作用域整体联动；三视角「返回总台」按钮右缘对齐、绿色。

3. 对象视角可按 ID / 用户名 / 昵称 / 手机号 / 区域检索，整页数据联动到所选对象。

4. 超级管理员可写可代操作；运维管理员只读，黄色提示条 \+ 操作禁用。

5. 角色与权限：总台管理员展开 5 职能角色且位阶正确；功能权限复选框按层过滤（代理 9 域 / 服务商 6 域）；编辑可保存权限组合。

6. 服务商入驻审核进总台审核队列；代理商辖区服务商支持初审 / 复审 / 业务升级审核。

7. 各页分类筛选按钮可点击并检索对应列表；搜索框支持清空叉；导出可用。

8. 详情对话框按页面业务定制（A 查看 / B 审核 / C 编辑 / D 仅编辑），驳回原因必填，编辑预填不空白。

9. 状态字段全部中文化，无英文键值；列表与对话框状态一致。

10. 四态（加载 / 空 / 异常 / 只读）齐全。
